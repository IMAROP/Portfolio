HOW THE DUAL AI SERVER & ENCRYPTED STORAGE PIPELINE WORKS
01 // PROFILE MEDIA
Photo & Video Upload

User creates a profile with photos, videos, age, and bio inside the bot.

02 // 2 AI ENGINES
Multi-Server AI Check

Checked by 2 separate AI engines on different servers (1 primary high-power engine + 1 secondary engine) to block bad/NSFW images.

03 // SAFE STORAGE
Firebase + TG Encryption

Data is stored on Google Firebase while all 11,000+ photos are stored on Telegram servers with custom encryption.

04 // MATCH & CHAT
Tinder Swipe & RAM Queue

Instant profile matching alerts or zero-latency Omegle anonymous chat in RAM.

01 // TINDER-STYLE DATING & MATCH ENGINE

Browse Profiles, Like, Dislike & Instant Alerts

Users create safe profiles with their picture, video, age, and details. They can browse through profiles just like Tinder—clicking Like notifies the other person immediately, while the Match Engine displays mutual matches so users can connect, chat, send messages, or report rule-breakers.

02 // OMEGLE-STYLE RAM ANONYMOUS CHAT

In-Memory Queue & In-Chat Matching

Anonymous chat runs directly in RAM link. Even if 100 people are waiting in the queue, clicking chat picks a random stranger immediately just like Omegle. Users can also click “Match” right inside an anonymous chat if both like each other.

03 // MINI WEB APP, ADSCRAM AI & STARS

Gender Filters, Points Economy & Shop

Both dating and anonymous chat feature Gender-Based Filtering (Girls or Boys) using Bot Points. Points are earned by watching video ads in a custom security-hardened Web App monetized with Adscram AI, referring friends, or converting Telegram Stars into points. Includes an in-bot Shop and profile editor.

04 // ENGINEERED FOR THOUSANDS OF USERS

Stress-Tested for 3,000+ Concurrent Live Chatters

Single-handedly built and refined over months without spending money on paid servers. Tested extensively with simulated virtual connections sending messages to each other so that even if 3,000 users live chat simultaneously on free-tier infrastructure, the system never cracks.
