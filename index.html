HOW THE DUAL AI SERVER & ENCRYPTED STORAGE PIPELINE WORKS
01 // PROFILE MEDIA
Photo & Video Upload

User creates a profile with photos, videos, age, and bio inside the bot.

02 // 2 AI ENGINES
Multi-Server AI Check

Checked by 2 separate AI engines on different servers (1 primary high-power engine + 1 secondary engine) to keep profile media clean and safe.

03 // SAFE STORAGE
Firebase + TG Encryption

Data is stored on Google Firebase while all 11,000+ photos are stored on Telegram servers with custom encryption.

04 // MATCH & CHAT
Discovery & RAM Queue

Instant profile matching alerts or zero-latency random pairing in RAM.

01 // SOCIAL DISCOVERY & MATCH ENGINE

Browse Profiles, Like, Dislike & Instant Alerts

Users create safe profiles with their picture, video, age, and details. They can browse through profiles—clicking Like notifies the other person immediately, while the Match Engine displays mutual matches so users can connect, chat, send messages, or report profiles.

02 // RAM-LINKED RANDOM CHAT QUEUE

In-Memory Queue & In-Chat Matching

Random 1-on-1 chat runs directly in RAM link. Even if 100 people are waiting in the queue, clicking chat pairs two users immediately. Users can also click “Match” right inside a conversation if both want to connect.

03 // MINI WEB APP & POINTS ECONOMY

Custom Filters, Points System & Shop

Both discovery and live chat feature preference filtering powered by Bot Points. Points are earned via a custom security-hardened Mini Web App integrated with Adscram AI, user referrals, or Telegram Stars conversion, alongside an in-bot Shop.

04 // ENGINEERED FOR THOUSANDS OF USERS

Stress-Tested for 3,000+ Concurrent Live Chatters

Single-handedly built and refined over months without spending money on paid servers. Tested extensively with simulated virtual connections sending concurrent messages so that even if 3,000 users live chat simultaneously on free-tier infrastructure, the system stays rock-solid.
